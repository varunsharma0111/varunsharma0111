### 🧪 Verification-First Engineering

**Implemented does not mean verified.**

```text
Code → Unit Tests → Integration Tests → API Tests → Browser/UI Tests
→ Runtime Verification → Security Checks → Regression Testing → Final Verification
```

**Engineering Principles:**
- Inspect existing code before making changes
- Understand the current architecture before modifying it
- Identify root causes instead of applying random fixes
- Prefer existing dependencies and standard libraries where appropriate
- Avoid unnecessary architectural complexity
- Make the smallest safe change possible
- Test before declaring completion, retest after fixes
- Never report unverified work as complete
- Review security-sensitive changes carefully
- Keep humans responsible for important engineering decisions
